# Today / Rollup Logic — canonical definition

**Maintained by:** Otto · **Type:** Living spec · **Last updated:** 2026-07-10

This is the **single source of truth** for how Otto builds the daily list and the weekly rollup. Both the interactive chat commands ("today", "EOW rollup", etc.) and the scheduled tasks (`weekday-morning-todo`, the Monday rollup) follow this spec. If a scheduled task's prompt and this spec ever differ, **this spec wins** — reconcile the task to it.

## Ground rules

- **Date basis:** always compute "today" in `America/Denver`. Run `TZ=America/Denver date +"%Y-%m-%d %A"` first; never assume the date.
- **Definitions (by each item's `due:YYYY-MM-DD`):**
  - **Overdue** = due date strictly *before* today.
  - **Due today** = due date *equal to* today.
  - Items with **no due date are not due today** — omit them from the daily list.
- **Read-only by default.** Producing/surfacing the list never creates, edits, or completes anything. Changes happen only on an explicit request.
- **One instance of a recurring item.** When populating recurring calendar items onto the board, add only the current (or next-due) instance of a daily or weekly item. Never pre-load multiple future instances (e.g., a week of daily Zoho checks); the next instance is added when its day arrives.

## Sources (in order)

1. **`productivity/TASKS.md`** — sections `## Active` and `## Waiting On`. Parse each item's `due:`, `#tag`(s), and `@owner` (owners mainly on Waiting-On items). Show the bold title, its tag, and owner.
2. **`Company_Calendar.md`** — any recurring item that *lands on today*:
   - **Weekly** items → on today's weekday.
   - **Monthly** items → on today's day-of-month.
   - **Every-4-week payroll / expense** → per the "2026 pay periods" table (not monthly; the workweek runs Thursday→Friday).
   - **Coaching prep** tasks → anchored to the 3rd Friday.
   - Include only if it lands today.
3. **Knowledge KBs** — `Knowledge/Meeting_Intelligence_KB.md` and `Knowledge/Direct_Report_1on1_KB.md`. Surface still-open items (status not Done/Resolved) as **candidates only**, labeled "candidate (confirm)". Never add them anywhere without confirmation.

## Associated SOP links (daily list and the to-do Word doc)

For each actionable item surfaced for today, check the Operations Playbook (`Operations_Playbook.md` / `.html`) for an **active SOP** that governs that task.

- **If one exists,** show it next to the task and link it. In the Word to-do doc, link to the SOP heading in the rendered HTML using its anchor id: `Operations_Playbook.html#<slug>`, where the slug is the heading text lowercased with punctuation removed and spaces turned to hyphens (e.g., "SOP: Coaching program" becomes `#sop-coaching-program`). Heading anchors are generated by `build_docs.py` (the `toc` extension), so rerun it if headings change. The file URL uses the absolute path, URL-encoded (spaces `%20`, the apostrophe `%E2%80%99`).
- **If none exists,** mark the task "no SOP yet; consider adding one" so a gap is visible and can become a candidate SOP.
- Current active SOPs and anchors: mid-contract client check-in (`#sop-mid-contract-client-satisfaction-check-in-keep-stop-start`), candidate sourcing (`#sop-candidate-sourcing-talent-pool-channels-ontology-knowledge-graph`), job offer (`#sop-job-offer-offer-letter`), onboarding (`#sop-onboarding-new-hires`), compensation review (`#sop-compensation-review-salary-surveys`), coaching program (`#sop-coaching-program`), personnel file & retention (`#sop-personnel-file-records-retention`), offboarding (`#sop-offboarding`), expense reimbursement (`#sop-expense-reimbursement`), payroll processing (`#sop-payroll-processing`), dashboard weekly update (`#sop-financial-evaluation-dashboard-weekly-update`), project closing / financial close (`#sop-project-closing-financial-close`), trust & trustee relations (`#sop-trust-interaction-trustee-relations`), cash & staff plan (`#sop-cash-staff-plan`).

## Efficiency suggestions (automate / delegate / eliminate)

For each actionable item, add a short automate / delegate / eliminate suggestion **only where one clearly applies** (via AI, a hand-off to Lucas or Amanda, or an available tool). Do not force one onto every item.
- **Do not suggest delegating COO-only items:** QuickBooks export and the Zoho check are COO-restricted (permissions); leave them with JT.

## Mode A — Interactive "today" (and related chat commands)

Surface the day's list straight in chat: overdue and due-today tasks (from TASKS.md Active + Waiting On), today's Company Calendar items, and any KB open items due — each with an automate/delegate/eliminate note where one applies. Keep it concise and skimmable. Related chat commands ("EOW rollup", "prep me for <meeting>", "what's outstanding with <Lucas/Amanda>", "decisions this week") pull from the same sources per `Knowledge/INDEX.md` → Workflows.

## Mode B — Scheduled weekday morning list (read-only)

Same logic as Mode A, formatted exactly as below. Use "none" for any empty section. If nothing is overdue or due today, say so plainly and add a one-line encouraging nudge. End the run with a `<run-summary>` of one or two sentences on what was found and whether anything changed since the last run.

```
**Good morning, JT — <Weekday, Month D>**

**Overdue**
- ...

**Due today**
- ...

**On the calendar today**
- ...

**From meetings / 1:1s (candidates to confirm)**
- ...
```
