# _Shared

Cross-agent reference material that does not belong to a single agent.

Convention: keep templates and work products **within the owning agent's folder** (e.g., HR's offer template in `HR/Templates/`). Use `_Shared/` only for material several agents genuinely rely on — for example, shared brand assets, a common glossary, or org-wide reference data. When in doubt, it lives with the agent that owns it.
